GLN Classroom Tools — Flashcards Separate Sign-In Patch

Upload ALL files in this folder directly to the ROOT of your GitHub repository and replace the existing files when prompted.

What changes:
- Classroom Tools loads Flashcards with ?embedded=classroom.
- Embedded Flashcards uses a separate in-memory Firebase Auth session.
- A previously remembered standalone Flashcards login is NOT automatically restored inside Classroom Tools.
- Teachers must click Continue with Google in embedded Flashcards.
- Embedded sign-in/sign-out does not affect the standalone Flashcards login.
- Standalone Flashcards keeps its normal remembered sign-in.
- No Firebase rules change is required.
