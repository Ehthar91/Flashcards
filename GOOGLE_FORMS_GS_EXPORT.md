# Google Forms `.gs` Export

No web-app deployment is needed.

## Export

1. Open a class/deck you own.
2. Click Quiz.
3. Choose the quiz settings.
4. Click **Download Google Forms Script (.gs)**.

## Create the Google Form

1. Open Google Apps Script.
2. Create a New project.
3. Delete the starter code.
4. Paste the downloaded `.gs` file.
5. Save.
6. Select `createFlashcardsQuiz`.
7. Click Run.
8. Approve permissions if prompted.
9. Open the Execution log.

The log gives you the Form editor URL and student quiz URL. The Form is also saved in Google Drive.

Multiple-choice questions include correct answers and points automatically.

Type Answer questions are created as short-answer questions with points and the intended answer saved as feedback; review those in Google Forms if automatic grading is needed.
